Registro Transparente de Prompts

Este documento contiene el registro cronológico y transparente de los prompts utilizados con la IA (Claude) durante el desarrollo del proyecto Doña Tere, organizados por integrante.

Prompts de Emily

1. Paleta de colores
Propósito: Definir una paleta de colores para el negocio familiar de tamales, atole y pastelitos.
Prompt utilizado:
Doña Tere es un negocio familiar de tamales, atole y pastelitos. Quiero una paleta de 5 colores: primario, secundario para precios o alertas, de fondo y de texto.
Que se vea minimalista, tradicional y limpia. Dame el HEX de cada color, para qué usarlo y su contraste sobre el fondo.

2. Diseño de tarjeta de pedidos 
Propósito: Diseñar la estructura visual de las tarjetas de pedidos destacando estados y pagos sin depender solo del color.
Prompt utilizado:
En DonaTereApp, la pantalla de Pedidos muestra cliente, fecha de entrega, total y estado de pago. Quiero que el diseño de la tarjeta destaque el estado (Pendiente, Entregado, Cancelado) y el pago sin depender solo del color.
Propón la estructura de la plantilla (DataTemplate) con Grid y estilos de Styles.xaml, respetando la paleta de colores actual.

3. Plan de pruebas en Postman
Propósito: Crear un plan de pruebas para verificar el CRUD y el manejo de errores.
Prompt utilizado:
Necesito un plan de pruebas para la entrega de Doña Tere para postman donde pueda verificar el funcionamiento del crud y errores.

4. Mejoras de diseño UI en .NET MAUI
Propósito: Recibir retroalimentación y propuestas de mejora visual para las pantallas principales de la aplicación.
Prompt utilizado:
Mi proyecto Doña Tere es una app .NET MAUI con pantallas de Inicio, Productos, Pedidos, Clientes y Categorías. Adjunto capturas. ¿Qué le mejorarías al diseño para que se vea más profesional?


Prompts de Larrañaga

1. Ciclos infinitos en JSON 
Propósito: Resolver el problema del bucle infinito en las respuestas JSON de la API debido a relaciones circulares entre entidades.
Prompt utilizado:
Estoy haciendo pruebas en los endpoints de la API, pero el JSON se queda en un bucle infinito debido a las relaciones entre las entidades. ¿Cómo podemos configurar esto para evitar el ciclo?

2. Casos de prueba y cuerpos JSON para Postman
Propósito: Obtener una guía completa de pruebas para validar los endpoints de la API (Categorías, Clientes, Productos, Pedidos y Reportes).
Prompt utilizado:
roporcionarme unos casos de pruebas detallados para Postman que permita validar todos los endpoints de la API (Categorías, Clientes, Productos, Pedidos y Reportes), incluyendo la estructura del cuerpo de las peticiones (JSON).

4. Guía de integración de arquitectura Cliente-Servidor
Propósito: Entender la lógica y los pasos de integración entre la app cliente (DonaTereApp) y la API (DoñaTereApi) antes de implementar código.
Prompt utilizado:
Necesito tu guía y asesoramiento para estructurar la integración entre el cliente DonaTereApp y la Web API DoñaTereApi. Explícame los pasos y la lógica de la arquitectura sin darme el código directamente, quiero entender el flujo primero.


Prompts Generales y Depuración

Prompt de Servicios y Controladores
Propósito: Apoyo para escribir los servicios de conexión con la API, controladores y ViewModels.
Prompt utilizado:
Ayúdame a escribir los servicios que conectan la app con la API y algunos controladores y ViewModels para el proyecto Doña Tere.

Prompt de Solución de Errores
Propósito: Interpretar y resolver mensajes de error en el entorno de desarrollo.
Prompt utilizado:
Ayúdame a interpretar y solucionar estos mensajes de error de Visual Studio, MySQL y conexión HTTP (puertos, referencias entre proyectos y uso de localhost en el emulador).
